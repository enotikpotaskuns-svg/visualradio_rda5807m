Финальный стабильный релиз цифрового FM-приёмника с графическим Hi-Fi интерфейсом, управляемого через системную шину Linux с помощью народного программатора **CH341A** и радиочипа **RDA5807M**.

## ✨ Особенности релиза:
* **Интеллектуальный автопоиск (Software Scan):** Сканирует эфир (включая УКВ от 50 МГц) и автоматически замирает на станциях с чистым сигналом.
* **Ступенчатый аттенюатор (клавиша A):** Три режима чувствительности (`MAX` / `MID` / `LOCAL`) — спасает от запирания и хрипов звука вблизи телебашен.
* **9 ячеек памяти:** Быстрый вызов станций кнопками `1-9` и бесшумная перезапись пресетов через `m + цифра`.
* **Полная тишина на шине:** Опрос оптимизирован до 250 мс, что полностью убрало наводящийся цифровой треск из динамиков.
* **Прямой ввод:** Поддерживает ввод частоты с клавиатуры (автоматически чинит точки и запятые).

## 🔌 Распиновка подключения к ZIF-панели CH341A (Секция 24XX):
* **Пин 4 (Нижний ряд, у рычажка):** `GND` -> Земля радио
* **Пин 5 (Нижний ряд, дальше от рычажка):** `SDA` -> Данные I2C
* **Пин 6 (Верхний ряд, дальше от рычажка):** `SCL` -> Тактирование I2C
* **Пин 8 (Верхний ряд, у рычажка):** `VCC (3.3V)` -> Питание радио

## 🚀 Установка в один клик:
```bash
git clone https://github.com/enotikpotaskuns-svg/visualradio_rda5807m
cd visualradio_rda5807m
./install.sh
```
После установки переподключите USB-кабель и введите в любой папке: `visualradio`
